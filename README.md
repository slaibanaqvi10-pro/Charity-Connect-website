# Charity Connect

## Project Description
Charity Connect is a Django-based web application that connects donors, volunteers, and charitable organizations. Users can register, explore charity campaigns, make online donations, and volunteer for different causes through a simple and user-friendly interface.

## Features
- User registration and login
- Charity campaign management
- Online donation system
- Volunteer registration
- Admin dashboard
- Donation tracking
- Responsive user interface

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Git
- GitHub

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Charity-Connect-website.git
   ```
2. Open the project folder:
   ```bash
   cd Charity-Connect-website
   ```
3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
4. Apply migrations:
   ```bash
   python manage.py migrate
   ```
5. Run the development server:
   ```bash
   python manage.py runserver
   ```

## How to Run
Open your browser and visit:

http://127.0.0.1:8000/
